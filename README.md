# AI and Machine Learning - Workshop Series (6CS012)

This repository contains the complete practical coursework for the **Artificial Intelligence & Machine Learning** module. It showcases a structured progression through 11 workshops, focusing on data-driven problem solving and model implementation.

## 📂 Project Structure

* **`Workshop #1 - #11`**: Jupyter Notebooks containing core implementations, lecture examples, and laboratory exercises.
* **`/csv`**: Source datasets utilized for model training and exploratory analysis.
* **`/Report`**: Technical documentation and academic reporting of the findings.

## 🧠 Core Objectives
The series covers the end-to-end Machine Learning pipeline:
- **Data Engineering:** Cleaning, feature scaling, and preprocessing.
- **Exploratory Data Analysis (EDA):** Identifying patterns and correlations within datasets.
- **Model Development:** Implementing Supervised and Unsupervised Learning algorithms.
- **Evaluation:** Assessing model performance through metrics and visualization.

## 🛠️ Technical Stack
- **Language:** Python
- **IDE:** VS Code / Jupyter Notebooks
- **Key Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
